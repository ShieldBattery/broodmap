Analyze all base areas surveys each base's three nearest reachable anchored bases in both directions. Close, nearly parallel span observations are consolidated conservatively. The map-wide partition is cached; changing A or B only changes the highlight. Cancellation takes effect between origin searches. Candidate spans block analysis crossings only; normal routes stay unchanged. The overlay floods the resulting components, which may contain multiple bases. Green boundaries separate components with all proposed cuts applied; amber boundaries still have a route around them. This does not establish wallability or exhaustive entrance coverage.

Entrance surveys look outward from both A and B, marking width transitions within 32 build tiles of each base. Labels A1/B1 identify the surveyed end; terrain farther ahead supplies widening evidence. It is experimental, can miss other exits, and does not certify walls or engine unit fit.

Regions and passages are heuristic summaries of the active terrain. Minimum relative narrowing suppresses room splits where the connecting clearance barely decreases compared with the smaller peak; increase it to merge more regions. Passage radius is a local square-space measure, not corridor width or a unit-fit guarantee. Peak markers show regions with at least 64 cells; hover any cell for its region.

Base discovery uses a stock 4x3 depot-footprint heuristic. Orange lines show ground routes; dashed lines show air distance. Terrain defines resource clusters. Sites marked * require clearing small mineral patches or overlapping buildings. Occupied starts clear overlapping objects automatically; current routes keep them present. Candidate scoring balances mineral and gas access. Full placement legality and mover clearance are not established.

Clearance shows how far an empty square can extend from each cell center before touching blocked terrain, active map obstacles, or the map edge. Hover to see its radius in pixels. Adjust the color scale to reveal differences in wider areas; values above its maximum share the final color. This measures space in the grid; actual unit passage needs additional movement rules.

When enabled, static resources and grounded neutral buildings are respected. This approximation ignores moving units, mover size, and exact StarCraft engine pathing. Terrain-only mode excludes the static map obstacles; it does not imply every invincible object is removable.
